# Trung Bắc Cạn - Construction Operations App

## Project Overview
Mobile-first construction operations management application for earthwork and land leveling projects.

## Technical Stack
- HTML5 / CSS3 (Tailwind CSS)
- Vanilla JavaScript
- Mobile-First Responsive Design
- Offline-First Architecture

## Design System
- **Name:** Industrial Field Utility
- **Theme:** Light Mode
- **Primary Color:** #f97316 (Safety Orange)
- **Typography:** Inter
- **Roundness:** 4px (Industrial/Clean)

## Screen Inventory (Source Code Included Below)
1. **Đăng nhập (Login)**: Phone OTP and Email authentication.
2. **Bảng điều hành (Dashboard)**: Real-time production and project status.
3. **Danh sách dự án (Project List)**: Overview of active construction sites.
- **Trung tâm nhập liệu (Input Hub)**: Tile-based field data entry (Attendance, Hours, Volume).
5. **Trung tâm phê duyệt (Approval Center)**: Management workflow for field data.
